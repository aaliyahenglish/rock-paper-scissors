# Project Name : Rock Paper Scissors
For this game, the user will be asked to make choices and according to the choice of the user and the computer and then the result will be displayed along with the choices of both computer and user.


## Tech Stack

**Language Used : C**

**Code Editor: Visual Studio Code**

## Lessons Learned
 - This game consists of the declaration of the variables.
 - I learned about printf() and scanf() functions for displaying the content and taking the input from the user:
    - srand() and rand() which are used to generate random numbers in the range.
- game() function:
    - This function consists of if-else statments that will compare the choice of user and computer.
