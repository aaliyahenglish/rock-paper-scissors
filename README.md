# Project Name : Rock Paper Scissors 🪨 ✂️
For this game, the user will be asked to make choices and according to the choice of the user and the computer and then the result will be displayed along with the choices of both computer and user.


## Tech Stack 💻

**Language Used : C**

**Code Editor: Visual Studio Code**

## Lessons Learned 
 - Learned more about the C Standard Library
   - <math.h> → **provides mathematical functions for common operators.**
   - <stdlib.h> → **preprocessor directive used in C to import standard library, provides dynamic memory management, process control, string-to-number conversions, and random number generation.**
   - <time.h> → **provides standard types, macros, and functions to manipulate date and time.**
 - I learned about **printf() and scanf()** functions for displaying the content and taking the input from the user:
    - **srand() and rand()** which are used to generate random numbers in the range.
- **game() function**:
    - This function consists of if-else statments that will compare the choice of user and computer.
    - While running the code, the game function were not returning the values for all the control paths. So, I added "return -1" as a fallback for inputs that were not covered.
- I used a debugger for the first time, I had some minor bugs as missing semicolons and wrong letter to describe the random number input.
